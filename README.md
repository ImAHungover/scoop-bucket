# ImAHungover Scoop bucket

Windows apps for [Scoop](https://scoop.sh).

```powershell
scoop bucket add imahungover https://github.com/ImAHungover/scoop-bucket
scoop install imahungover/lore-chess
```

| App | What it is |
|---|---|
| `lore-chess` | [Lore Chess](https://github.com/ImAHungover/lore-chess-releases): chess against Stockfish, on a 2D board or in an animated 3D dungeon |

Lore Chess appears in the Start menu as **Lore Chess**. Update with `scoop update lore-chess`, and uninstall with `scoop uninstall lore-chess`. Saved games and settings stay in `%APPDATA%\Godot\app_userdata\Lore Chess`.
